# YoCoolRingtones

A simple 2000s-inspired ringtone website.

## Features

- 15 original ringtones
- WAV downloads
- MIDI downloads
- 2000s-style interface
- Static HTML, CSS and JavaScript
- GitHub Pages compatible

## Ringtones

1. Synthwave Lead
2. Marimba Bounce
3. Vibraphone Call
4. Electric Guitar
5. Organ Pulse

7. Brass Signal
8. Warm Strings
9. Bassline Alert
10. Harp Cascade

12. Celesta
